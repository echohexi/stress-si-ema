## What MUST be disclosed (Elsevier 2024–2025 policy)

| Activity | Disclose? |
|---|---|
| AI used to assist drafting / re-phrasing prose | ✅ Yes |
| AI used to translate prose | ✅ Yes |
| AI used to summarise literature | ✅ Yes |
| AI used to generate / fabricate figures or images | ❌ Forbidden |
| AI used to generate scientific content (analyses, results, claims) | ❌ Forbidden |
| AI used to suggest references | ⚠️ Disclose AND verify every citation manually |
| Code assistants (Copilot, Claude Code) used to write data-cleaning or analysis code | Disclose if used substantively |
